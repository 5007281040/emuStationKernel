This readme outlines how to update the kernel. 


1. Prebuilding stuff

Simply run:

./kernelPullScript.sh

Make sure its marked as *Executable*. This simply updates the kernel IF
it needs updating. 

run

sudo chmod +x kernelPullScript.sh

2. Make sure you cd into the *linux* directory with 
cd linux

run the installation script with the previous steps, give the file

*installationScript.sh* executable privelages with

sudo chmod +x installationScript.sh

then, run the command with 

./installationScript.sh
